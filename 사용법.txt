냉장고 털기 · 휴대폰에 앱으로 설치하기
=====================================

이 압축 파일을 풀면 생기는 '냉장고털기-앱' 폴더(안에 index.html이 있는 폴더)를
인터넷에 올리면, 휴대폰 홈 화면에 진짜 앱처럼 설치할 수 있어요.
설치하면 주소창 없이 열리고, 한 번 열고 나면 인터넷이 없어도 열려요.


1. 인터넷에 올리기 (Netlify, 무료 · 컴퓨터에서 5분)
-------------------------------------
 ① 컴퓨터에서 https://app.netlify.com/drop 에 들어가요.
 ② 압축을 푼 폴더를 화면에 통째로 끌어다 놓아요.
    (폴더를 열었을 때 바로 index.html이 보이는 폴더여야 해요)
 ③ 다 올라가면 꼭 'Claim'(내 사이트로 가져오기)을 눌러 무료 계정에 연결하세요.
    연결하기 전에는 비밀번호로 잠겨 있고, 시간이 지나면 지워져요.
 ④ 생긴 주소(예: https://이름.netlify.app)를 휴대폰으로 보내요.
    카카오톡 '나와의 채팅'에 붙여넣으면 편해요.


2. 휴대폰에 설치하기
-------------------
 [아이폰 · 사파리]
 ① 주소를 사파리에서 열어요.
    (카카오톡에서 누르면 카카오톡 안에서 열려요. 메뉴에서 사파리로 열거나, 주소를 복사해 사파리에 붙여넣으세요)
 ② 아래쪽 ⋯ 버튼 → 공유 → '홈 화면에 추가'를 눌러요.
    (iOS 18 이하는 아래쪽 공유 버튼을 바로 누르면 돼요)
 ③ '웹 앱으로 열기'가 켜져 있는지 보고 '추가'를 눌러요.
 ※ 아이폰은 사파리에서 쓰던 데이터와 홈 화면 앱의 데이터가 따로예요.
   설치한 다음부터는 홈 화면 아이콘으로 여세요.

 [안드로이드 · 크롬]
 ① 주소를 크롬에서 열면 앱 위쪽에 '앱으로 설치' 안내가 떠요. '설치'를 누르세요.
    (카카오톡 안에서 열렸다면 메뉴에서 다른 브라우저(크롬)로 여세요)
 ② 안내가 안 보이면 오른쪽 위 ⋮ → '홈 화면에 추가' → '설치'.

 [삼성 인터넷]
 메뉴 ≡ → '현재 페이지 추가' → '홈 화면'.


3. 설치하면 이렇게 쓸 수 있어요
------------------------------
 - 안드로이드는 아이콘을 길게 누르면 '지금 뭐 먹지 · 재료 넣기 · 장보기 · 먹은 것 기록' 바로가기가 나와요.
 - 안드로이드는 뒤로 가기 버튼으로 열린 창을 닫을 수 있어요.
 - 요리 모드에서는 화면이 꺼지지 않게 잡아두고, 타이머는 다른 화면에 가도 계속 돌아요.
   다만 앱을 나가거나 화면을 끄면 끝나는 순간에 알람이 안 울릴 수 있어요.
 - 새 버전을 올리면 앱을 열 때 '새 버전이 준비됐어요 · 새로고침'이 떠요.


4. 데이터 (꼭 읽어주세요)
-----------------------
 - 앱 버전은 재료와 기록을 그 휴대폰 안에만 저장해요. 앱을 지우면 데이터도 같이 지워져요.
 - 가끔 설정(오른쪽 위 톱니) › 데이터 › '백업 파일 저장'을 눌러두세요.
   한 달 동안 백업을 안 했으면 냉장고 탭에서 알려줘요.
   아이폰은 '파일에 저장'이나 카카오톡 '나와의 채팅'으로 보내두면 돼요.
 - 데이터는 주소별로 따로 저장돼요. 다른 주소로 새로 올리면 빈 앱이 되니, 백업 파일로 옮기세요.
 - claude.ai에서 쓰던 데이터를 옮기려면:
   claude.ai 버전 설정 › 데이터 › '백업 파일 저장'(또는 '글로 복사')
   → 앱 버전 설정 › 데이터 › '백업 파일 불러오기'(또는 '글 붙여넣기').


5. 새 버전으로 바꾸기 (주소와 데이터 그대로)
------------------------------------------
 - Netlify에서 내 사이트 → Deploys 화면에 새 폴더를 끌어다 놓으면 같은 주소에서 바뀌어요.
 - Drop 화면에서 바로 이어서 올린다면 'Keep dropping'으로 같은 주소에 다시 올릴 수 있어요.
 - 휴대폰 앱은 다음에 열 때 새 버전을 받아요.


6. claude.ai에서만 되는 기능
---------------------------
 - 사진으로 재료 넣기, Claude 셰프, 유튜브·블로그 레시피 가져오기, 요리 질문은
   claude.ai에서 열었을 때만 돼요. 나머지는 앱에서 모두 돼요.
 - claude.ai 버전은 내 계정에 저장돼서 여러 기기에서 같은 냉장고를 볼 수 있어요.
